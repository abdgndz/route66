# Route 66 site v1 (review draft) implementation plan

> **For agentic workers:** executed inline (superpowers:executing-plans). Steps use checkbox syntax.

**Goal:** Build a review draft of the Route 66 Driving School site and deploy it to a Cloudflare `workers.dev` preview URL, so Michael can review it.

**Architecture:** An Astro 7 static site. All business data lives in `src/data/site.ts`, and the components read only from that file. Styling is plain CSS with design tokens in `src/styles/global.css`. The only JavaScript is one small script in `src/scripts/contact.ts` (the WhatsApp chooser and the sticky bar). A `DRAFT` flag in `site.ts` turns on the draft banner, highlights placeholder values, and sets `noindex`.

**Tech stack:** astro 7.3.5, @astrojs/sitemap 3.7.4, @fontsource/barlow and @fontsource/barlow-condensed 5.3.0, @playwright/test 1.63.0, @axe-core/playwright 4.13.0, wrangler 4.147.0.

## Global constraints
- No third-party runtime scripts. No cookies.
- Copy never says "pass rate", "best", "guaranteed", "No.1" or "DVSA approved instructors". The approved wording is "DVSA Approved Driving Instructor (ADI)".
- JSON-LD type is `["LocalBusiness","EducationalOrganization"]`, with no rating or review markup.
- WhatsApp links use the format `https://wa.me/<digits>?text=<encoded>`, where the digits start with `44`.
- Tap targets are at least 44px. Text contrast is at least 4.5:1. Motion is turned off under `prefers-reduced-motion`.
- While `DRAFT` is true, every page has `<meta name="robots" content="noindex,nofollow">`, `robots.txt` contains `Disallow: /`, and the server sends the header `X-Robots-Tag: noindex`.

## File map
- `astro.config.mjs`: site URL and sitemap.
- `wrangler.jsonc`: Workers static-assets config.
- `public/_headers`: security headers and noindex.
- `src/data/site.ts`: all content plus helpers `waLink(number, text)`, `telLink(number)` and the `ph()` placeholder marker.
- `src/layouts/Base.astro`: head, SEO tags, JSON-LD, header, footer, draft banner, sticky bar.
- `src/components/*.astro`: Header, Footer, Logo, Hero, TrustStrip, Instructors, Services, Steps, Reviews, Areas, Faq, Contact, WaChooser, StickyBar, CarArt.
- `src/pages/index.astro`, `lessons.astro`, `privacy.astro`, `terms.astro`, `404.astro`, `robots.txt.ts`.
- `src/scripts/contact.ts`: chooser open/close and sticky-bar visibility.
- `tests/site.spec.ts`: Playwright and axe checks.
